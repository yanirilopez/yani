Guía Interactiva: Convenciones de Estilo y Nomenclatura

Plataforma de Aprendizaje de Estilo

Estudio de buenas prácticas en HTML y JavaScript moderno.

1. Nombres Significativos e Interacción con el DOM

Incorrecto

Abreviaturas crípticas que obligan a adivinar el propósito de las variables.

let n = "Pedro";
function calc(x) {
  return x * 1.16;
}
Correcto (Clean Code)

Nombres descriptivos en formato camelCase que se autoexplican.

let nombreUsuario = "Pedro";
function calcularPrecioConIva(precioSubtotal) {
  return precioSubtotal * 1.16;
}

2. Indentación Estructurada (HTML + JS)

Incorrecto

Código plano, sin jerarquía visual. Hace imposible detectar errores de cierre.

<div>
<button id="btn">Enviar</button>
<script>
function alertar(){
alert("Listo");
}
</script>
</div>
Correcto (2 o 4 espacios)

Estructura anidada limpia. Permite entender la relación entre HTML y bloques de Script.

<div>
  <button id="btnEnviar">Enviar</button>
 
  <script>
    function mostrarAlertaExito() {
      alert("Listo");
    }
  </script>
</div>

3. Longitud de Líneas y Saltos de Bloque

Incorrecto

Línea horizontal kilométrica. Fuerza al desarrollador a hacer scroll lateral innecesario.

<input type="email" id="txt_eml_usr" class="input-primary large-size dark-theme text-left border-blue rounded-corners shadow" placeholder="Introduce tu correo electrónico corporativo aquí" required="true">
Correcto (Atributos Multi-línea)

Atributos ordenados verticalmente cuando exceden los 80 caracteres. Lectura natural de arriba a abajo.

<input
  type="email"
  id="inputCorreoUsuario"
  class="input-primary large shadow"
  placeholder="Introduce tu correo aquí"
  required
>
